How Adcraft is put together.

Adcraft makes ads — static, product video, presenter video — pushes them to Meta, TikTok and Google, reads the results back, and starts the next round from what worked. It is one Next.js application in a pnpm monorepo, backed by Postgres, with every long-running job run through Inngest.

1 · System overview

One container, one database, everything else behind an adapter.

The browser talks only to the Next.js app. The app reads and writes Postgres directly from server components and server actions, stores media in object storage, and hands anything longer than a request to Inngest, which calls the app back to run the pipeline. Every external system — AI models, ad platforms, billing, email — sits behind a package adapter with a sandbox or a no-op when its key is missing.

Decision

One deployable

App, pipelines and the Chromium-backed video renderer share a container. No serverless timeouts, no separate worker to keep in sync; scaling is a bigger box first.

Decision

Jobs through Inngest

Anything over a request — concepts (~75 s), renders, HeyGen work, publishing, insights — is a function with retries and a dashboard. Local dev can run them inline.

Decision

Adapters with sandboxes

Missing keys degrade to sandbox providers and disabled models rather than errors, so the whole loop is demoable with zero credentials.

Decision

Catalogue, not constants

Models live in ai_models plus built-ins; admins add, disable or re-price a model without a deploy. Pipelines resolve models by id at run time.

Six ways in, each with a fixed shape.

Public API/api/v1/creatives, /api/v1/files/*Bearer API keys (hashed). Outbound webhooks on creative.rendered, approval.*, comment.added.

Auth is Auth.js v5: Resend magic links, Google OAuth when configured, and a dev credentials box outside production. middleware.ts protects everything except /api/* and static assets. Roles are owner · editor · viewer per membership; platform admins come from ADMIN_EMAILS.

4 · The creative loop

This is the product. Everything else serves it.

library

Product

Photo stored, background removed by fal BiRefNet (product/cutout). URL import tries Shopify /products/<handle>.js, then JSON-LD, then Open Graph.

briefs

Brief

The input step. briefPrefillFromCreative lets Performance and the Next panel open a brief already filled from a creative.

concepts/generate

Ideas

Claude returns eight concepts — hook, angle, platform-ready copy, visual direction — shaped by the brand kit's tone and do/don't lists.

static/generate · render/variants

Static ad

An editable document rendered with Satori + resvg (brand fonts, cutout composited by the template), or an AI scene from fal behind the same template. Every placement size in one run.

video/generate

Product video

Per-scene stills → image-to-video clips (Kling, Veo, Seedance, Runway…) → Remotion assembles each size with captions and an end card.

ugc/generate

Presenter video

ElevenLabs or HeyGen voice → HeyGen presenter render → B-roll clips → ffmpeg assembly with captions and hook. Steps skip when their asset already exists.

characters

Character studio

Generated characters, photo avatars, prompt characters and digital twins on HeyGen; looks from packs, templates or remixes; cloned and designed voices per workspace.

campaigns · publish/campaign

Campaign

Account → audience → placements & budget → ads → review. Spec check and claims review gate the review step; spend above the threshold needs an owner. Published paused.

performance · insights/cron

Performance

Hourly sync into metrics_daily; the page derives spend, CTR, CPA, ROAS, per-creative rows and fatigue alerts, with Refresh and Pause.

5 · Background work

A job is a typed payload, a pipeline function, and one Inngest wrapper.

  1. Registry. src/server/jobs.ts names every job and its payload type; src/pipelines/index.ts registers inline handlers; src/inngest/functions.ts wraps the same functions with createFunction. Without INNGEST_EVENT_KEY, dispatch() runs the handler in-process, fire-and-forget.
  2. Credits. reserveGenerationCredits charges up front — concepts 1 · static ad 2 · 15 s video 20 · 30 s presenter video 40 · HeyGen look 3 · avatar 5 · digital twin 25. Failures refund; partial results refund the difference.
  3. Idempotence. Video and presenter documents keep every generated asset; re-running skips steps whose asset exists, so a failed B-roll clip never re-bills the voice-over.
  4. Guardrails run before dispatch. Monthly provider budget, credit cap, rate limits and voice slots are checked in the server action, so a blocked job never reaches the queue.

7 · Cross-cutting

Guardrails, brand safety, collaboration, billing, observability.

server/guardrails.ts

Guardrails

Monthly provider budget per workspace (platform default), optional credit cap and spend-approval threshold, token-bucket rate limits on generation starts and uploads, HeyGen voice slots, optional approval-before-publish. Settings → Guardrails; Admin → Guardrail defaults.

packages/ads/claims.ts

Brand safety

reviewClaims() scans copy for medical, financial, guarantee, superlative, personal-attribute, false-urgency and profanity claims. Hard findings block publishing, soft ones warn; brief constraints harden matching categories.

server/collab.ts · share.ts

Collaboration

Comments, approvals (draft → in_review → changes_requested → approved), share links for client review, team roles and invites, an audit log of settings and publishing actions.

server/billing.ts

Billing

Stripe subscriptions (Starter / Studio / Agency, monthly or yearly) grant credits; top-ups add; every generation debits credit_ledger. Trial credits and signups are platform settings.

/api/health · instrumentation.ts

Observability

Health with per-check latency; unhandled server errors posted to Sentry's envelope endpoint when SENTRY_DSN is set; Admin shows provider status, generations with cost, platform metrics.

tests · e2e

Testing

Node test runner for server logic; Playwright golden path against a dev server — sign-in → dashboard → library → brief pre-fill → Next panel → five-step campaign builder on a sandbox account → performance → guardrails → health. No provider spend.
